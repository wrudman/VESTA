# Extra Intel MKL-accelerated dependencies for Linux x86_64.
#
# This file is a *delta* on top of requirements.txt.  It does NOT replace
# the base file — on Linux x86_64 (glibc >= 2.27) you install both:
#
#     uv pip install -r requirements.txt
#     uv pip install --reinstall-package numpy --reinstall-package scipy \
#         --index-strategy unsafe-best-match \
#         -r requirements-extra-mkl.txt
#
# Why --reinstall-package:
#   requirements.txt already installed numpy/scipy from PyPI (vendored
#   OpenBLAS).  This file swaps them for MKL-linked wheels from
#   urob/numpy-mkl at the SAME pinned versions.  Without --reinstall-package,
#   uv would skip them because they are already present.
#
# Why --index-strategy unsafe-best-match:
#   Tells uv to prefer the extra-index-url for packages that exist there
#   (numpy, scipy, mkl, intel-openmp, ...).  Without it, uv resolves from
#   PyPI first and would reinstall the same OpenBLAS-vendored wheels.
#
# Platform compatibility:
#   Linux x86_64 (Ubuntu/Debian/RHEL/Fedora/Amazon Linux)  --  YES
#   macOS (any architecture)                               --  NO (use Accelerate, see requirements.txt)
#   Linux ARM64 (Graviton, Ampere)                         --  NO (MKL is Intel-only)
#   Windows                                                --  NO (urob wheels untested here)
#
# Verify after install:
#   python -c "from threadpoolctl import threadpool_info; \
#              [print(d['prefix'], d.get('threading_layer')) for d in threadpool_info()]"
#   Expected:  'libmkl_rt intel'  --  NOT  'libscipy_openblas pthreads'.
